# 可组合的数学构造动作

只在 [构造工作台](design-workbench.md) 需要生成机制时，选读相关一节。这些是从等式或条件推导算子的工具，不是五个固定模型，也不构成新颖性声明。纯密码构造使用对应安全锚点，不因本文件有概率或“保证”字样而套用 AI 算子。

| 实际瓶颈 | 先尝试的动作 | 必须保留的接口 |
|---|---|---|
| 大量成对交互反复计算 | 1. 函数交互可分离化 | 被逼近的函数、query 域与输出误差 |
| 有廉价但不够准确的近似 | 2. 廉价基线加随机残差 | 基线均值可得、采样支持完整 |
| 固定深度无法表达所需求解过程 | 3. 把层写成带输入的不动点 | 状态空间、收缩条件与停止残差 |
| 局部改动影响远端输出 | 4. 分配可传播的误差预算 | 实际状态、扰动来源、后续放大 |
| 何时继续计算取决于尚未知的信息 | 5. 付费观测与序贯决策 | 决策前信息、转移与成本 |

## 1. 函数交互可分离化

**先定义交互函数，再压缩它。** 对 $q,k_j$ 与列向量 $v_j\in\mathbb R^{d_v}$，目标为

$$y(q)=\frac1n\sum_{j=1}^n\kappa(q,k_j)v_j.$$

若构造 $\kappa_r(q,k)=\phi(q)^T\psi(k)$，$\phi,\psi\in\mathbb R^r$，则

$$S=\frac1n\sum_j\psi(k_j)v_j^T\in\mathbb R^{r\times d_v},\qquad y_r(q)=S^T\phi(q).$$

对有限特征函数，这个求和重排是精确的；$\kappa_r$ 对 $\kappa$ 的近似是另一件事。若指定域上 $\sup|\kappa-\kappa_r|\le\epsilon$ 且 $\|v_j\|\le B$，三角不等式直接给出 $\|y-y_r\|\le B\epsilon$。该界要求覆盖部署 query 的域。

**由此构造模块**：把 token/边交互变成可累积统计 $S$ 与 query 特征。计算特征的成本之外，构建需 $O(nrd_v)$，单 query 读出需 $O(rd_v)$；流式均值应维护未归一化和及计数，窗口删除还需相应数据。多个 query 共享统计才可能摊薄构建成本；特征参数更新后，旧统计量通常需要重建。

一种有来源的特征构造是 RFF：对定义在 $\mathbb R^d$ 上的实值、连续、平移不变、PSD、$\kappa(0)=1$ 的核，Bochner 谱概率分布 $p$ 给出 $\omega_\ell\sim p,b_\ell\sim U[0,2\pi]$，$\phi_\ell(x)=\sqrt{2/r}\cos(\omega_\ell^Tx+b_\ell)$，其内积期望等于核。它不是任意交互函数的通用公式，也不自动给统一近似界。[Rahimi–Recht 原论文](https://proceedings.neurips.cc/paper_files/paper/2007/hash/013a006f03dbc5392effeb8f18fda755-Abstract.html)

**先检查什么**：显式成对求和与因子化实现的一致性；独立 query 上的函数/输出误差；query 域外对照。普通 RFF 可产生负相似度，不能直接当概率；归一化 attention 还需控制分母远离零并重推误差界。

## 2. 廉价基线加随机残差

**把精确计算花在近似没解释的部分。** 对固定输入下的有限向量集合 $a_j$，目标 $\mu=n^{-1}\sum_j a_j$。构造廉价 $b_j$ 且能精确便宜地求 $\bar b=n^{-1}\sum_jb_j$；取 $J_i\overset{iid}{\sim}p$，所有 $p_j>0$：

$$\hat\mu=\bar b+\frac1{mn}\sum_{i=1}^m\frac{a_{J_i}-b_{J_i}}{p_{J_i}}.$$

条件于固定的基线和输入，逐项求期望可得 $\mathbb E\hat\mu=\mu$。均匀采样时 $\operatorname{Cov}(\hat\mu)=\operatorname{Cov}_J(a_J-b_J)/m$。它只在残差协方差足够小时优于直接采样，系数取 1 不自动降低方差。[Owen，Monte Carlo 第 8.9 节](https://artowen.su.domains/mc/Ch-var-basic.pdf)

**由此构造模块**：可分离统计、低秩近似或离线训练的廉价预测器算基线，只对抽到的边/专家计算精确残差。计入基线构建、样本数、精确交互及 gather 成本；若仍需访问原始 keys/边，不能同时宣称省掉了这些存储。

**先检查什么**：小全集上枚举抽样，核对期望；用高相关与反相关基线比较方差；在相同总预算下比较误差。不能先算完全部 $a_j$ 再免费选最优采样分布。同批样本拟合基线系数再回填可能有偏，应独立拟合或重做证明。

无偏仅针对上述线性均值。除以另一随机分母、softmax、argmax 或非线性损失后一般不再无偏；涉及参数相关采样时还需单独推导梯度估计。不要据此声称“无偏 attention/无偏训练”。

## 3. 把层写成带输入的不动点

**把“算多少层”改成“求到什么残差”。** 固定输入 $x$，令

$$z_{t+1}=T_\theta(z_t,x)=\phi(Az_t+Bx),\qquad z^*=T_\theta(z^*,x).$$

例如逐坐标 1-Lipschitz 的 $\phi$ 与 $\|A\|_\infty\le c$、$0\le c<1$，在完备空间 $\mathbb R^d$ 的无穷范数下保证收缩；矩阵无穷范数是最大绝对行和。可用 $A=cM/\max(1,\|M\|_\infty)$ 强制这一充分条件；估计谱半径小于 1 不能替代该全局非线性条件。

由 $\|z-z^*\|\le\|z-T(z,x)\|+c\|z-z^*\|$，得到

$$\|z-z^*\|\le\frac{\|T(z,x)-z\|}{1-c}.$$

**由此构造模块**：用可计算残差决定停止，保存最大迭代数和未收敛标志。每次注入 $Bx$ 能让平衡点依赖输入，但 $B=0$、非单射投影或激活饱和仍可能使不同输入塌缩；要测输入区分性，不能从收缩性推出它。

若 $T$ 可微、局部 $I-J_zT$ 可逆，精确平衡点满足 $(I-J_zT)\,dz^*/d\theta=\partial_\theta T$。隐式反传需解相应转置线性系统；截断反传和未收敛前向有另外的误差。将网络作为求解问题的已有路线见 [DEQ 原论文](https://proceedings.neurips.cc/paper/8358-deep-equilibrium-models.pdf)；这里的收缩参数化只是一个易核查构造，不是所有 DEQ 的假设。

**先检查什么**：$\phi=I$ 时与解析线性解比较；验证残差上界、不同输入的平衡点以及 $c\to1$ 的迭代成本；破坏范数条件测试失效。计入前向迭代、反向求解和 batch 最慢样本的影响，再决定是否适合目标硬件。

## 4. 分配可传播的误差预算

**把局部“变化小”改成所需输出上的误差。** 完整状态更新为 $h_{k+1}=F_k(h_k)$，候选为 $\hat h_{k+1}=\hat F_k(\hat h_k)$。若在涉及的域上 $F_k$ 为 $L_k$-Lipschitz，并能控制 $\delta_k=\|F_k(\hat h_k)-\hat F_k(\hat h_k)\|$，令 $e_k=\|h_k-\hat h_k\|$，则

$$e_{k+1}\le L_ke_k+\delta_k,\qquad e_L\le\sum_{k=0}^{L-1}\delta_k\prod_{j=k+1}^{L-1}L_j\quad(e_0=0).$$

这是由逐层三角不等式得出的条件界；输出读出若为 $L_{out}$-Lipschitz，还需乘该因子。

**由此构造模块**：按传播到输出的代价分配压缩/跳过/求解误差预算；优先把计算花在误差会被放大的位置。实际状态要含影响未来的缓存与历史；只分析当前 token 向量，不覆盖改变 KV-cache 后的后续生成。

关键限制：决策前精确计算 $\delta_k$ 可能已支付被省略操作的成本。需结构上可得的界或只依赖已有状态的预测器；teacher 轨迹可作离线标签，预测值仍不是确定性证书。全局常数乘积过大时应降为诊断或在明确数据假设下研究更紧界。

**先检查什么**：构造“局部误差小、后续放大大”的对照，与仅按 hidden-state 距离分配预算的基线比较。小域观测或校准不能自动推广为所有输入保证。相关锚点：[matrix-perturbation](../knowledge-base/matrix-analysis/matrix-perturbation.md)。

## 5. 付费观测与序贯决策

**把 gate 分数改成继续计算的价值。** 状态 $s_t$ 只含决策前已知信息。有限时域停止问题可写成

$$V_t(s)=\min\{\ell_{stop,t}(s),\ c_t(s)+\mathbb E[V_{t+1}(s')\mid s,continue]\},$$

其中停止代价在必要时是条件期望，末时刻 $V_T=\ell_{stop,T}$。这条递推在指定状态充分、转移、加性期望代价与可选动作下定义最优策略，不保证拟合出的价值网络最优。[MIT 最优停止讲义](https://ocw.mit.edu/courses/6-231-dynamic-programming-and-stochastic-control-fall-2015/resources/mit6_231f15_lec5/)

**由此构造模块**：把“多做一步能减少多少风险”与成本比较，训练条件价值/收益预测。若动作是跳过一个子层而非永久退出，则使用包含 skip/compute 后继状态的动作 Bellman 式，不能直接套停止递推。

**先检查什么**：在可枚举的小状态系统上与动态规划 oracle 比较，另测短视规则；检查是否偷看尚未支付的特征或被跳过层输出。离线完整轨迹与执行新策略后的状态分布不同，需 rollout/覆盖检查；硬延迟上限还需显式预算状态或约束，平均惩罚不能保证逐样本预算。

## 组合时保留哪条结论

例如动作 1 提供廉价、可精确求均值的基线，动作 2 对残差采样修正，可以形成新的聚合候选；其线性均值无偏性需要完整采样支持与固定基线，不能传递到任意归一化输出，也不自动消除原数据存储。

动作 3 的残差可提供停止规则，动作 5 可优化平均成本；若价值网络允许在残差未达标时停止，则放弃了原逐样本误差门槛，应明确改成了哪种风险目标。

组合不是把两段术语拼在一起：推导接口，构造破坏接口的反例，再决定是否值得实现。
