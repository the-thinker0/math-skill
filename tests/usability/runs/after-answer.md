建议主做**受输出误差预算约束的分组跳层，并用低秩桥接补上状态和 KV**。第一轮只改 2–4 个相邻双层组，冻结完整模型；容易的 token 使用廉价桥接，难的 token 执行原层组。研究重点是“用多少近似误差换多少计算”，以及跳层后怎样继续保持有效状态。

先把“保持输出”具体化为同一前缀上的 teacher/student logits 差异、下一 token 分布 KL 和贪心 token 一致率；自由生成另测完整续写。两周内可以验证这种质量—计算权衡，暂时不能承诺 GPU 延迟收益。

**可直接实现的前向。** 对准备跳过的两层 \(g=(a+1,a+2)\)，当前已有 \(h_a\in\mathbb R^d\)。用一个共享低维表示产生中间层和组末状态：

\[
u_g=\operatorname{GELU}(V_g\operatorname{LN}(h_a)),\quad
\widetilde h_{a+j}=h_a+U_{g,j}u_g+b_{g,j},\ j=1,2,
\]

其中 \(V_g\in\mathbb R^{r\times d}\)、\(U_{g,j}\in\mathbb R^{d\times r}\)，首轮 \(r\in\{8,32\}\) 做两个独立候选，随后固定胜出的秩。桥接提供的是近似 residual 更新，输出坐标仍与原网络一致。执行原层组时直接使用原实现；使用桥接时不运行这两层的 attention 聚合和 FFN。

跳过组内第 \(j\) 层时，仍从该层的近似输入 \(\widetilde h_{a+j-1}\) 计算它自己的 K/V 并写入缓存，约定 \(\widetilde h_a=h_a\)：

\[
\widetilde k_{a+j}=W^K_{a+j}\operatorname{LN}_{a+j}(\widetilde h_{a+j-1}),\quad
\widetilde v_{a+j}=W^V_{a+j}\operatorname{LN}_{a+j}(\widetilde h_{a+j-1}).
\]

实际实现沿用原模型的 normalization、位置编码/RoPE、head 布局和 cache position。这些是**近似 KV**，不是完整模型的真实 KV；但之后的 token 可以正常访问每一层的历史。不能留下缺失位置，也不能给所有层复制同一份 K/V。首轮 prefill 用完整模型，decode 才启用该机制。

**数学依据：按最终输出的变化计费。** 只看 \(\|h_{a+2}-\widetilde h_{a+2}\|\) 不够。我实际运行了二维诊断：两个同为 \(10^{-3}\) 的局部误差，经过 \(\mathrm{diag}(1000,1)\) 后分别成为 \(1\) 和 \(10^{-3}\)。同一个 hidden-state 阈值会接受两者，输出误差预算则能区分它们。

更直接的分析可以避开松得不可用的逐层 Lipschitz 常数乘积。令 \(S_g\) 是执行到组 \(g\) 前的实际状态，包含当前 hidden state 和全部 KV；\(F_g\) 是原组映射，\(B_g\) 是桥接映射，\(G_{g+1}\) 是从组后状态运行剩余完整层到 logits 的函数。定义当前实际状态上的跳层代价

\[
d_g(S_g)=\|G_{g+1}(F_g(S_g))-G_{g+1}(B_g(S_g))\|_\infty.
\]

把逐组替换的混合执行结果作望远镜求和，直接得到

\[
\|\ell_{\rm full}-\ell_{\rm adaptive}\|_\infty
\le \sum_{g\text{ 被桥接}} d_g(S_g).
\]

这里 full 与 adaptive 从**同一个 token 前缀缓存状态**出发，每个 \(d_g\) 必须在已经发生先前跳层的实际 \(S_g\) 上定义，而不是一律取完整 teacher 轨迹上的值。这是三角不等式给出的当前推导，不假设后续层线性。

如果真能保证累计代价不超过 \(\epsilon\)，那么 teacher 最优 logit 与次优 logit 的间隔大于 \(2\epsilon\) 时贪心 token 不变；同时 \(D_{KL}(p_{\rm full}\|p_{\rm adaptive})\le2\epsilon\)，由 log-sum-exp 对无穷范数的 Lipschitz 性得到。上述量词是“同一个前缀缓存状态上的当前 token”。累计历史 KV 已与原 teacher 不同时，它不自动保证完整生成一致。

**推理不能计算这个 \(d_g\)，否则已经花掉要节省的计算。** 因此把它作为离线监督，训练一个小预测器

\[
q_g=f_\psi(\operatorname{LN}(h_a),\ g,\ t,\text{此前跳层记录},\text{剩余预算})\ge0.
\]

这些量在决策前都已知。teacher 的后层状态、teacher entropy、真实 \(d_g\)、尚未计算的 attention 输出以及未来 token 都不能进入该输入。小预测器先用宽度 32 的共享 MLP 加组嵌入，输出风险估计；计算量也计入总成本。

每个 token 初始化预算 \(b=\epsilon\)，组 \(g\) 的可用额度取 \(b/(\text{剩余可跳组数})\)；若 \(q_g\) 在额度内且桥接估算成本低于完整组，就执行桥接并令 \(b\leftarrow b-q_g\)，否则执行完整组。未使用的预算自然留给后组。这个规则是可复现的保守启发式，不宣称是全局最优分配；之后可以学习额度分配，但首轮没有必要。

这里的 \(q_g\) 是预测值，**上述确定性结论只对真实 \(d_g\) 或有效上界成立**。首轮使用偏重低估惩罚的分位数回归，并在独立调参集选择安全裕量；最终在未参与调参的集上统计闭环累计真实代价、预测低估率和质量。不把分位数网络或调好的裕量称为逐样本证书。预算可解释了算法，但经验校准仍然决定实际保真程度。

**训练安排。** 先用已有完整轨迹蒸馏桥接状态，损失包含组内 hidden-state MSE、对应 KV MSE，以及组后完整后缀产生的 logits KL。三项分别解决状态接续、未来缓存和输出保持；hidden/KV 损失按坐标数及 teacher RMS 归一化，初始权重各取 1，KL 权重在独立调参集选定。原模型冻结，梯度经过冻结后缀回到桥接参数；冻结权重不等于切断后缀对输入的梯度。

然后收集随机 compute/bridge 路径和当前策略路径。在同一个实际学生状态上分叉执行 compute 与 bridge，两支各跑完整后缀，取得 \(d_g\) 标签；完整 teacher 轨迹单独不足以提供这些反事实标签。训练风险预测器时标签停止梯度，不用硬路由的 STE。做两轮“收集路径—回归预测器”，避免预测器只认识完整 teacher 状态。

KV 的后续影响用额外的短窗口检查处理：从两支分叉缓存继续 teacher-force 同样的后续 8 个 token，记录未来最大 logit 偏差和 KL。把这个窗口误差加入预测标签的最大值，会比仅看当前 token 更保守；窗口内的真实未来 token 只在离线生成标签时出现。它仍不能给任意长自由生成一个确定性保证，所以最终必须测真实闭环 decode，不能只跑 teacher forcing。

这一构造的可检验增量是桥接补偿、包含 KV 的输出代价和共享误差预算。去掉桥接会变成直接丢弃 residual；去掉输出代价会回到局部相似度判断；去掉预算会让多个局部小误差无约束叠加。三项都应通过消融决定是否值得保留。动态深度和自适应退出已有先例：[Mixture-of-Depths](https://arxiv.org/abs/2404.02258) 研究按 token 分配计算，[CALM](https://arxiv.org/abs/2207.07061) 明确讨论了自适应退出和历史表示缺失；[ADEPT](https://arxiv.org/abs/2601.03700) 的摘要也以动态早退的 KV 问题为重点。当前组合是否有论文新颖性，仍需针对桥接和风险预算细查这些方法，不能仅靠数学表述判断。

**两周的最小验证。** 使用一个能承担反事实执行成本的现成小 decoder-only checkpoint；优先沿用用户已有模型与轨迹，首轮只动 2 个双层组、上下文 128、续写 32 token。按 prompt 划分约 200 条训练、50 条调参、100 条测试，避免同一 prompt 的 token 跨集合泄漏。若现有资源不足以跑该规模，就先把 checkpoint 缩小和 prompt 减半，不能把下载、完整大模型训练或完整路由树枚举默认为两周内已经可行。

| 时间 | 应完成的可检查结果 |
|---|---|
| 第 1–2 天 | 接好完整路径与桥接路径；无跳层时输出和缓存与原实现一致；先跑一小批测离线成本 |
| 第 3–5 天 | 桥接 hidden/KV/输出蒸馏；选择秩 8 或 32；检查始终桥接的质量上限 |
| 第 6–8 天 | 生成反事实输出代价、第一轮风险回归和策略 rollout，检查推理输入无 teacher 泄漏 |
| 第 9–10 天 | 用实际学生轨迹补标签、第二轮回归，在调参集选预算与安全裕量 |
| 第 11–14 天 | 固定方案，跑独立测试和消融，输出完整质量—计算曲线与失败样本 |

对照至少包括完整模型、同理论计算量的固定跳层、hidden 相似度跳层、普通二元 gate，以及本方案去桥接/去预算。统一 KV 补全方式和可训练参数量，否则比较混入其他差异。报告下一 token KL、PPL、贪心一致率、32-token 自由生成偏差，以及不同难度分组的实际计算分配。难度分组可离线用 teacher NLL 或标注定义，不作为推理的免费输入。

建议第一轮继续条件是：在**相同输出质量**下，包含桥接、预测器与 KV 投影后仍能降低理论计算，并优于同成本普通 gate；可预先把 20% 理论 MAC 减少作为工程目标，而不是结果预告。若只比完整模型省而不胜过 gate，不能据此认定新增结构有效。

成本上，两层桥接约 \(3dr\) 次主矩阵 MAC，另加归一化、激活及每层 KV 投影 \(2dd_{kv}\)。省掉的是对应 Q/O、attention 聚合与 FFN；所有原模型参数仍存在，KV 存储也没有因此减少。动态 batch 的打包和 kernel 启动可能抵消收益。当前没有 GPU 测速数据，只报告操作数和待测的 prefill/decode、batch size、P50/P95 延迟，不写“加速多少倍”。

已运行的局部诊断见 [代码](after-probe/verify_skip_budget.py) 和 [数值结果](after-probe/skip-budget-results.json)。它支持“相同 hidden 误差的输出影响可能相差很大”，尚未验证 Transformer 上的桥接、风险预测或质量收益。
