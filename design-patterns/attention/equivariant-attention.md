# 等变注意力 / Equivariant Attention
> **证据标注**：[v] 有明确假设或记录验证支持；[~] 待验证的工程方案；[x] 在所述条件下不相容；[N/A] 不适用。伪代码用于定义算子，不是完整生产实现。

## 适用问题
当输入具有**明确的对称群 $G$ 作用**（旋转、平移、置换、反射等），且期望模型输出在相同变换下**协变**（equivariant）而非不变时，需要将等变约束直接编入注意力机制。典型场景：3D 点云/分子（$E(3)$ 刚体群）、图像分类（$D_n$ 旋转/镜像群）、集合数据（$S_n$ 置换群）、多视角/多传感器融合。

## 需要的数学知识

- 明确输入/输出表示：$f(\rho_{in}(g)x)=\rho_{out}(g)f(x)$。
- token 置换 $P$ 下，得分变为 $S'=PSP^T$，注意力权重变为 $A'=PAP^T$，输出变为 $O'=PO$。权重矩阵并非原封不动，而是索引同步重标。
- Schur 引理：不等价不可约表示间的 intertwiner 为0；同一有限维复不可约表示的副本之间，在不可约因子上为标量，在重数通道间可任意混合。实不可约表示的交换子代数未必只有标量。
- 单个 $SO(3)$ 的 $\ell$ 阶不可约表示有 $2\ell+1$ 个分量；0至 $L$ 阶各一份共 $(L+1)^2$ 个。反射等变还需奇偶类型。

## AI 模块形式

**置换等变**（逐行共享映射；mask 与位置须一致变换）：
```python
Q, K, V = W_q(X), W_k(X), W_v(X)
A = softmax(Q @ K.T / sqrt(d), dim=-1)
output = A @ V
# 对 X' = P @ X：A' = P @ A @ P.T，output' = P @ output
```
固定因果 mask 或绝对位置通常破坏任意 token 置换对称性。

**旋转/平移等变**：用相对距离及不变张量收缩等不变量构造标量得分，再用标量权重聚合有表示类型的等变 Value。仅用平移不变标量输入，不会使绝对坐标向量自动平移等变。逐项检查位置输入、Value 投影、非线性、残差及输出类型。

**有限群对称化**（通用但昂贵的参照构造）：
$$F(x)=\frac1{|G|}\sum_{g\in G}\rho_{out}(g)^{-1} f(\rho_{in}(g)x).$$
等变输出必须带逆输出变换；直接平均 $f(\rho_{in}(g)x)$ 会构造不变映射。24元素旋转子群只能保证该有限群等变，不是精确 $SO(3)$ 或 $E(3)$ 等变。

## 可实现结构
- **SE(3)-Transformer / Equiformer**：球谐特征 + 等变注意力，用于分子性质预测和蛋白质结构
- **Set Transformer**：$S_n$ 置换等变注意力 + Induced Set Attention（低秩诱导点降复杂度）
- **G-CNN 注意力**：$D_n$ 旋转/镜像等变，用于遥感图像和医学影像

## GPU 可行性

- **D1/D2[~]**：共享逐点映射及注意力用 GEMM；张量积与不可约表示混合需要类型感知的核。置换等变无需枚举 $n!$ 个元素。
- **D3/D4[~]**：通用有限群对称化约需 $|G|$ 次基础计算；激活峰值取决于批处理/分块。精确连续群构造使用表示约束，不枚举无限群。
- **D5[~]**：在 fp32 与目标精度测试相对等变残差 $\|F(gx)-\rho_{out}(g)F(x)\|/(\|F(x)\|+\epsilon)$，包括反射及数值奇异点附近旋转。
- **D6/D8[~]**：独立群计算可批处理，但不蕴含 $|G|$ 倍墙钟加速；测量 launch、带宽与张量积开销。
- **D7[N/A]**：表示稀疏本身不会产生可用的稀疏注意力核。

## 论文表述方式

“不变标量得分与保持表示类型的 Value 映射保证所指定的等变性。报告等变残差及参数、显存、延迟、任务质量的实测变化；轨道大小不能单独决定参数节省。”

## 风险

- 按预测目标验证对称性：能量可旋转不变，力应旋转等变；手性任务可能不适用反射。
- 高阶张量积及通道重数增加成本；按任务消融选择截断阶数。
- 无约束共享线性映射、归一化、偏置或非线性可能破坏非平凡群等变性；测试整个模块，不只注意力权重。
