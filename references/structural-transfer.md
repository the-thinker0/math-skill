# 从结构缺口发现跨数学领域思路

用户要求跨领域启发、不同数学方向、跳出现有范式时读取。目标是找到能改变研究判断的结构对应，不是为已有模块换名。生成阶段先从问题关系出发；选定映射后再查现有设计原型作为对照和实现参照。[构造工作台](design-workbench.md) 用于随后实例化机制，不是每条理论见解的必经步骤。

## 让任务关系决定去哪里找

去掉模型/模块名字，保留当前方案缺少的一条关系。例如“融合多个专家”可以进一步拆成：单个观测各自不充分；希望利用联合信息；只传预测值时是否已经丢失不可恢复的信息。后者能指向统计充分性、函数空间与投影，前者容易只匹配到 routing 模板。

从用户真正的矛盾中选取必要线索：什么操作应可交换或保持不变；哪些局部结果需要兼容；信息在哪一步被丢弃；什么量需要可加、可组合或受界控制。用户未给数学名字时，也应主动提出数学表述；已有明确表述时不重新发明需求。

沿关系寻找新的表述，而不是先限定领域名单：

| 可以寻找的桥 | 要核查的具体关系 |
|---|---|
| 同一结构的不同语言 | 例如可观测信息对应可测函数空间；双方的运算、目标和量词是否一致 |
| 对偶或证据 | 一个可行性/优化问题能否改写成证书、价格或分离条件；强对偶等条件是否满足 |
| 商与提升 | 去掉对称性后能否稳定选择代表；若不可能，是否应保留轨道、纤维或多解分布 |
| 局部到整体 | 局部一致是否足够；未被局部检查发现的全局障碍是什么 |
| 极限或离散化 | 某个连续/离散表述能否提供新算法；极限、近似误差和运算顺序是否可交换 |

这些是寻找关系的方式，不是五个必选工具。沿定义、等价表述、定理假设和一手来源中的引用扩展到未预置领域；15 个透镜、41 张锚点、22 个原型及五个构造动作都不是搜索边界。优先核验能决定桥是否成立的命题，而非整本书或整片领域。

## 交出真实的结构对应

每个值得推荐的迁移都需要说明：

- 任务中的对象、关系或损失，对应来源数学中的什么；哪些信息和操作被保留。
- 所用命题的准确条件，以及迁回本问题能得到的等式、不等式、不可能性或可执行操作。
- 对应是精确等价、充分条件、带误差近似，还是尚未证明的类比；不能互相替代。

至少展开一条关键推导。如果只剩“像流形、像层、像博弈”，没有能被代入和检验的关系，就继续查缺口，或把它保留为低置信度联想。学习得到的张量不会因为命名而满足公理；为模拟器引入不存在的 oracle 也不是有效归约。

发现不可能性、不可辨识性或信息不足同样有价值：它可以说明应换表示、增加观测、放松目标或保留多解。不要为了交一个“新模块”，绕过这些结论。

## 按研究价值筛选，而不是按数学名称筛选

用户要多个方向时，保留在信息接口、机制、保证或研究问题上确实不同的候选。两个不同名字的加权平均，或两个只换正则系数的 loss，不算两条跨域路线。

对每条候选，找到一个它与当前基线会产生不同结果的小输入族，再找一个迁移无益或条件失效的对照。说明差异来自哪条数学关系，以及会换来什么代价。可观察的价值可以是更强表示、更低计算/样本成本、更可靠的保证，或排除一条不可能的研究路线；不要求都表现为 GPU 加速。

结构需要的观测拿不到、假设没有实现方式或成本超出硬约束时，暂不推荐为主线。已知的数学迁移可以有工程价值；要声称研究新颖性，须检索目标领域最近邻工作，分别指出已有部分、当前推导和待验证的迁移。没完成检索就不写“首次”。

交付先讲哪条思路值得试、它改变什么，再给对象对应、关键推导、来源与最小区分实验。无需照抄本文件的过程表。用户只要方向时，不擅自扩成完整实现项目。

## 一条完整桥：信息融合不等于预测平均

**任务缺口**：各专家只能看见部分信息，怎样利用互补信息？先区分“融合已有预测”与“允许访问联合信息”。

**概率 → 函数分析**：对实值 $Y\in L^2(\Omega,\mathcal F,P)$ 与子 $\sigma$-代数 $\mathcal G$，$P_{\mathcal G}Y=\mathbb E[Y\mid\mathcal G]$ 是到闭子空间 $L^2(\mathcal G)$ 的正交投影。因此对 $f\in L^2(\mathcal G)$，

$$\mathbb E(Y-f)^2=\mathbb E(Y-P_{\mathcal G}Y)^2+\mathbb E(P_{\mathcal G}Y-f)^2.$$

这条对应将“允许观测的信息”变成“可以表达的预测函数空间”。有限训练得到的普通专家不自动等于该 Bayes 投影。[Pitman，STAT205 §10.2.3](https://www.stat.berkeley.edu/~pitman/s205f02/lecture15.pdf)

**迁回 AI 后出现的边界**：令 $X_1,X_2$ 独立服从 Bernoulli$(1/2)$，$Y=X_1\operatorname{XOR}X_2$。两个单视图最优专家都输出 $1/2$，任意归一化加权平均仍是 $1/2$，MSE 为 $1/4$。联合观测可用 $Y=X_1+X_2-2X_1X_2$ 零误差预测。

所以合并信息空间 $\sigma(X_1)\vee\sigma(X_2)$，不等于平均两个空间上的预测。**由此得到的机会**是改变专家间的信息接口，保留有用分支信息并允许交互；只调预测权重无法解决这个反例。若原始信息已不可访问，就应报告信息不足。实验用 XOR 与加性目标对照“仅传预测”与“允许联合信息”；这不意味着所有专家平均都无效。

更多展示真实结构对应和反例的例子见 [迁移桥示例](transfer-bridges.md)：覆盖空间到多解表示、局部一致性到纠错距离。只在需要校准迁移质量时读，不把示例当固定推荐路线。
