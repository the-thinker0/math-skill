我建议主做**“低秩跨层状态预测 + 输出风险约束的跨度选择”**：在一个固定深度入口，由当前可见状态一次决定跨越 0、2 或 4 层；用一个便宜的联合预测器生成这段的近似 hidden states，同时补齐各层 KV。第一轮冻结原模型，只训练预测器和风险预测头。

研究假设是：**部分输入的多层状态变化，能从跳过前的状态在低维空间中预测，而且预测误差在输出敏感方向上足够小。** 这是要验证的假设，不是 Transformer 普遍成立的性质。它把“输入难度”操作化为“保持教师输出需要多少计算”，不预设高熵 token 或数学 token 一定需要更多层。

这条路线有明确的相近工作：FlexiDepth 已经使用逐层 router、轻量 adapter，并为跳过的 token 计算 KV；因此“gate 加 adapter 加 KV”不能单独作为新意。这里值得验证的是**一次联合预测多个深度的状态，以及按实际输出损失选择跨度**。[FlexiDepth，§2](https://arxiv.org/html/2503.23798v1)

**1. 先把第一轮的机制固定下来。**

令完整模型有 (L) 层，(h_{t,l}) 是处理到第 (l) 层后的当前 token 状态。第一轮只在一个中部位置 (l) 决策，候选动作 (k\in\{0,2,4\})，跳过第 (l+1,\ldots,l+k) 层，然后继续执行剩余层。保留首尾层；例如 24 层模型先试 (l=12)。先做 decode、batch size 1，prefill 正常执行，降低实现和归因难度。

输入只用已算出的 (h_{t,l})、位置及历史路由摘要，不访问当前 token 在更深层的状态，也不使用未来 token。定义共享瓶颈：

\[
z_t=\operatorname{SiLU}(V\operatorname{Norm}(h_{t,l})+b),\qquad z_t\in\mathbb R^r,
\]
\[
\widehat h_{t,l+s}=h_{t,l}+U_s z_t+c_s,\quad s=1,\ldots,4,
\]

其中 (V\in\mathbb R^{r\times d})、(U_s\in\mathbb R^{d\times r})，先取 (r=64)，再用 (r=32,128) 做小范围消融。不同深度的头共享同一个 (z_t)，而不是串行运行四个 adapter。路由头也读取 (z_t)，预测各候选跨度的输出风险。推理时先决定 (k)，只物化该动作需要的状态头；(k=0) 时执行原始层。

这里的控制变量是整个连续区间的跨度，替代算子直接近似这段计算产生的联合状态变化。它仍需要一个选择器，但主要研究对象已经超出逐层二元 gate。

**2. KV cache 必须进入定义，不能留给实现阶段补救。**

对被跳过的第 (j=l+s) 层，缓存应从它的近似**输入**状态产生：

\[
\widetilde h_{t,j-1}=
\begin{cases}
h_{t,l},&s=1,\\
\widehat h_{t,l+s-1},&s>1,
\end{cases}
\]
\[
\widetilde K_{t,j}=\operatorname{RoPE}_t\!\left(W^K_j\operatorname{Norm}_j(\widetilde h_{t,j-1})\right),\qquad
\widetilde V_{t,j}=W^V_j\operatorname{Norm}_j(\widetilde h_{t,j-1}).
\]

上式按采用 RoPE 的 pre-norm 模型书写；实现沿用原模型的归一化和位置处理。保留原始 K/V 投影，跳过 Q 投影、attention 聚合、O 投影和 MLP。缓存每层、每个位置都有条目，所以后续困难 token 可以恢复执行任意层；这些条目的**内容是近似的**，并不等同于完整模型缓存。

因此本方案准确的成本口径是“跳过主要层计算，保留 KV 写入”。(k=0) 也只能避免当前 token 新增跳过误差，不能修复之前产生的近似缓存；不要把回退称为恢复完整模型输出。

推理顺序就是：执行前缀层 → 从当前状态选跨度 → 预测所需状态并写入被跳过层 KV → 从跳跃终点执行后缀 → 输出下一个 token。整个过程中不需要先运行被跳过的层。也不要直接用跨序列 top-k 来筛选 token：Mixture-of-Depths 原文明确讨论了这种排名在自回归生成中的非因果性。[Mixture-of-Depths，§3.5](https://arxiv.org/html/2404.02258v1)

**3. 数学依据支持哪些结论？**

先将训练样本的联合残差组成矩阵，每行是

\[
D_i=[h_{i,l+1}-h_{i,l};\ldots;h_{i,l+4}-h_{i,l}]^\top\in\mathbb R^{4d}.
\]

对列中心化后的 (D\in\mathbb R^{N\times4d})，最佳秩 (r) 逼近满足

\[
\min_{\operatorname{rank}(A)\le r}\|D-A\|_F^2=\sum_{j>r}\sigma_j(D)^2.
\]

这是截断 SVD 的结论，可以用来判断共享低维输出空间是否容量不足、初始化 (U_s)。但它只说明这些残差**可被低秩表示**，不说明潜变量能由 (h_{t,l}) 预测。必须另外测 held-out 预测误差。比如不同前缀在入口产生近似相同的状态，却需要不同的后续 attention 更新，仅看入口状态的预测器就会有不可消除的误差。

保输出还需要第二层依据。把跳跃终点 hidden state 和会影响输出的 cache 合成状态 (S)，跳过产生扰动 (\delta S)。令后续完整计算的 logits 为 (a(S))，教师分布 (p=\operatorname{softmax}(a(S)))。在可微、足够小的扰动邻域内，

\[
\operatorname{KL}(p\|q)
=\tfrac12\delta S^\top J^\top\bigl(\operatorname{diag}(p)-pp^\top\bigr)J\delta S
+o(\|\delta S\|^2),
\qquad J=\frac{\partial a}{\partial S}.
\]

这说明相同 hidden-state MSE 可以带来截然不同的输出变化：误差方向和后续放大都重要。第一版不需要构造巨大 Fisher 矩阵，直接用末端教师—学生 KL 蒸馏，就在优化真正关心的分布误差。

还能得到一个有条件的严格界：由于 log-sum-exp 的 Hessian 谱范数不超过 (1/2)，

\[
\operatorname{KL}(p\|q)\le\tfrac14\|a(S+\delta S)-a(S)\|_2^2
\le\tfrac{K^2}{4}\|\delta S\|_2^2,
\]

其中第二步要求这段状态邻域内的后续映射是 (K)-Lipschitz。第一步是 softmax 的性质；第二步的 (K) 在这里未知，可能很大，因此不是已经取得的推理证书。缓存误差必须包含在 (\delta S) 中，不能只控制当前 hidden state。

小 KL 也不保证生成文本完全相同：教师第一、第二名 logits 间隔很小时，小扰动就能翻转 greedy 输出。若 logits 的无穷范数误差小于教师间隔的一半，则当前 argmax 保持；跨多个 token 的文本保持还需要逐步成立。实验应分别报告分布保真和文本一致率。

**4. 训练与决策：先学替代计算，再学它什么时候可靠。**

第一阶段，用完整模型状态训练联合预测器：

\[
\mathcal L_{\mathrm{bridge}}=
\sum_{s=1}^4\frac{\|\widehat h_{l+s}-h^T_{l+s}\|_2^2}{\|h^T_{l+s}\|_2^2+\epsilon}
+\beta\mathcal L_{KV}
+\gamma\operatorname{KL}(p_T\|p_S).
\]

(\mathcal L_{KV}) 对实际写入的 K/V 与教师 K/V 做逐层归一化误差匹配；KL 来自真正替换区间后继续执行模型的结果。先用状态损失预热，再加入 KV 和 KL，并按各损失的验证表现调权重。教师冻结并停止梯度；学生侧保留穿过冻结后缀层回到预测器的梯度，不能把学生整个后缀包在 `no_grad` 中。

第二阶段，在训练前缀的同一个**学生缓存快照**上，离线分叉 (k=0,2,4) 三种动作，计算真实后果作为风险标签。定义

\[
D_{t,k}=\frac1H\sum_{u=t}^{t+H-1}
\operatorname{KL}\bigl(p_T(\cdot\mid x_{\le u})\|p_{S,k}(\cdot\mid x_{\le u})\bigr).
\]

先做 (H=1) 的密集标签，再在抽样前缀上做 (H=8\) 或 (16)：分支只改变当前动作，此后执行同一个冻结续行策略、喂入相同 token 前缀，但保留各分支自己的缓存。这样可以看见“当前输出没变、缓存却伤害后续输出”的情况。训练时可以访问教师深层状态和未来标签；推理特征不能包含它们。

风险头预测 (D_{t,k})，对低估施加更大损失，或做高分位回归。将误差校准留给独立验证集，得到保守预测 (\widehat D^{\mathrm{cal}}_{t,k})。推理选择

\[
k_t=\arg\min_{k\in\{0,2,4\}} C(k)
\quad\text{s.t.}\quad\widehat D^{\mathrm{cal}}_{t,k}\le\varepsilon;
\]

无动作满足时取 (k=0)。(C(k)) 包含预测器、KV 和实际执行层的 FLOPs；不假设误差随跨度单调。阈值控制计算—误差折中，**校准预测不是逐 token 的数学保证**。先画误报率和保留误差随阈值的曲线，再选工作点。

教师状态上的离线标签可能过于乐观。第一版至少做一轮学生路由 rollout，用实际学生状态及缓存重新采样、补标签、微调预测器和风险头；训练、校准、测试按完整文档或 prompt 分割，不能随机拆相邻 token。正式测试还要独立自由生成，覆盖文本前缀逐渐分叉后的行为。

**5. 暂无 GPU 测速时，先把能节省什么算清楚。**

以单 token 解码为口径，隐藏宽度 (d)，K/V 总宽度 (d_{kv})，SwiGLU 中间维 (m)，缓存长度 (T)，乘加计 2 FLOPs，单层主要成本约为

\[
C_{\mathrm{layer}}\approx4d^2+4dd_{kv}+6dm+4Td.
\]

分别对应 Q/O、K/V、MLP 和 attention 两次矩阵乘；忽略归一化、激活、softmax 等较小项。跳过 (k) 层时保留 (4kdd_{kv}) 的 KV 投影，再付出共享下投影、所需状态头约 (2dr+2kdr) 以及风险头成本。因此净节省约为

\[
\Delta C(k)\approx k(4d^2+6dm+4Td)-2dr-2kdr-C_{\mathrm{risk}}.
\]

这是理想算术量估计。实际占比还应加入未跳过层、词表输出头及 prefill；单个 4 层区间在 24 层模型上，连原始层数口径都最多省 (4/24\)，保留 KV 和额外预测后会更低。第一轮可以把“完整 decode 算术量减少约 8%”设为探索目标，不预设倍数加速。

预测器参数约 (5dr)；例如 (d=2048,r=64)，约 65.5 万个权重，bf16 约 1.31 MB。一次生成四个状态头的临时张量为 ([B,4,d])，bf16 约 (8Bd) bytes，共享瓶颈另占 (2Br) bytes。整个 KV 仍占约 (4LBTd_{kv}) bytes，没有缓存容量收益；原模型权重也仍需保留。训练全层状态若全部落盘需约 (2N(L+1)d) bytes，宜只存目标区间并分块产生 KL，避免存完整词表分布。

分支、很小的矩阵乘、KV 写入和 kernel 启动可能吃掉理论收益。先实现 batch 1；后续 batch (B>1) 按三个动作分组时，必须计入 gather/scatter 和小批量效应，不能把平均跳过层数直接写成吞吐提升。KL 用 fp32 的 `log_softmax` 与累加；低秩残差相加检查 bf16 舍入误差，并比较 fp32/bf16 下路由翻转比例。没有设备测量时，报告净 FLOPs、状态量和质量曲线，延迟/吞吐保持“未测”。

**两周按下面的顺序推进。** 假设能运行一个冻结的 0.5B–1.5B 模型及其短后缀反向；如果设备受限，优先缩模型和样本数，不扩大跳跃区间或候选数量。

| 时间 | 具体产物 | 用来决定什么 |
|---|---|---|
| 第 1–2 天 | 选现有可运行模型；约 5 万 token 的区间状态；联合残差谱、训练/验证预测误差 | (r\le128) 是否有足够容量，入口状态是否可预测；若谱好而预测差，问题在可观测性 |
| 第 3–5 天 | 训练状态预测器；实现 0/2/4 层真实分支和 KV 写入；验证零跳过与原模型数值一致 | 机制能否在后续 token 恢复深层计算；静态桥接本身损失多大 |
| 第 6–8 天 | 三动作风险标签；抽样短窗口后果；风险头及独立校准集 | 能否区分同跨度下的安全和危险输入，而非只学平均跳过率 |
| 第 9–10 天 | 一轮学生缓存 rollout 和重标注；冻结最终策略 | 教师状态与学生轨迹间的偏移是否可控制 |
| 第 11–14 天 | 同 FLOPs 比较、自由生成与长上下文压力测试、阈值曲线；可用时做设备测速 | 是否形成值得扩展的保真—计算前沿 |

第一轮保留四个核心比较：完整模型；静态跨度加同款预测器；逐层普通 gate 加同预算 adapter/KV；本方案。相近基线可采用受控的 FlexiDepth 风格实现，但要注明是否完整复现原方法。用相同训练 token、相近新增参数、相同净 FLOPs 比较。再做两个关键消融：移除状态补偿，以及移除短窗口/cache 后果监督。离线真实风险选动作的 oracle 仅作性能上限，不能计入可部署结果。

测试用成对、长度尽量匹配的简单复制/模板续写与多步算术输入，加普通文本验证集。报告平均与尾部 KL、perplexity 变化、同前缀 next-token 一致率、自由生成任务准确率、平均净 FLOPs；按生成长度分桶查看缓存误差是否累积。难度分组用于解释策略，实际输出风险才是它应预测的对象。

建议事先定一个探索性继续标准：在独立测试集上，至少一个工作点达到约 8% 净 decode FLOPs 节省、perplexity 相对增加不超过 1%，且自由生成任务准确率下降不超过 1 个百分点，并优于同预算静态桥接；同时给出按 prompt 重采样的置信区间。样本不足以分辨 1 个百分点时，结论应是证据不足。若联合残差不低秩、风险头接近常数、或者短期 KL 很小而长生成明显退化，就分别否定低秩假设、自适应选择价值或缓存控制效果，优先据此收缩方案。
